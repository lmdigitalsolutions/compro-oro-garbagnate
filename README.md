# Compro Oro Garbagnate Milanese

Sito web a scroll animato per Compro Oro Garbagnate Milanese (Via Giuseppe Garibaldi 50, 20024 Garbagnate Milanese MI).

- Dominio: https://compro-oro-garbagnate.it/
- `index.html`: pagina unica (testi, meta SEO, canonical e dati strutturati JSON-LD per negozio, orari e FAQ).
- `frames/`: i 62 fotogrammi JPEG dell'animazione, caricati in sottofondo.
- `img/`: le immagini delle card dei servizi.
- `robots.txt` e `sitemap.xml`: per l'indicizzazione su Google.
- `og.jpg`: anteprima di condivisione (WhatsApp, social).
- Animazione: fotogrammi disegnati su canvas in base allo scroll.
- Sezioni: animazione iniziale, servizi, recensioni Google, FAQ, contatti e orari.
