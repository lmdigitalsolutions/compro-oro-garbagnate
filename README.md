# Compro Oro Garbagnate Milanese

Sito web a scroll animato per Compro Oro Garbagnate Milanese (Via Giuseppe Garibaldi 50, 20024 Garbagnate Milanese MI).

- `index.html`: pagina unica e autonoma. I fotogrammi dell'animazione e le immagini dei servizi sono incorporati, quindi basta aprire il file o pubblicarlo su qualsiasi hosting statico (per esempio GitHub Pages).
- Animazione: 62 fotogrammi JPEG disegnati su canvas in base allo scroll.
- Sezioni: animazione iniziale, servizi, recensioni Google, FAQ, contatti e orari.
